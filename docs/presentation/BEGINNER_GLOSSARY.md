# 11. BEGINNER GLOSSARY — Словарь терминов

> Формат: **Term** — простое объяснение · *по-русски* · где в TurtleTalk.

## Backend и API

| Term | Объяснение | Где в проекте |
|---|---|---|
| **API** | Набор «дверей», через которые одна программа просит другую что-то сделать · *программный интерфейс* | 33 эндпоинта FastAPI |
| **Endpoint** | Конкретный адрес + метод, например `POST /mnemonics` · *точка доступа* | `api/routes/*.py` |
| **REST** | Стиль API: ресурсы — это URL, действия — HTTP-методы (GET читает, POST создаёт) | весь бэкенд |
| **HTTP status code** | Число, которое говорит, как прошёл запрос: 200 ок, 400 плохой запрос, 401 не вошёл, 403 нельзя, 404 нет, 429 слишком много, 503 сервис занят | `errors.py` |
| **Request / Response body** | Данные, которые отправляют и получают, обычно JSON · *тело запроса/ответа* | Pydantic-схемы |
| **JSON** | Текстовый формат данных `{"key": "value"}` | все ответы API и агентов |
| **FastAPI** | Python-фреймворк для API; проверяет данные и строит документацию по типам | `api/main.py` |
| **Pydantic** | Библиотека, которая проверяет форму и типы данных · *валидация* | `api/schemas.py` |
| **Dependency injection** | Функция получает нужные объекты «снаружи», а не создаёт сама · *внедрение зависимостей* | `api/deps.py` (`Depends`) |
| **Layered architecture** | Код разделён на слои с правилами, кто кого может вызывать · *слоистая архитектура* | routes → services → repositories |
| **Repository** | Класс, который один работает с базой данных · *репозиторий* | `repositories/` |
| **Service** | Класс с бизнес-правилами (use case) · *сервис* | `services/` |
| **Port / Adapter** | Порт — интерфейс «что мне нужно»; адаптер — конкретная реализация (например, клиент Tatoeba) · *порты и адаптеры* | `services/ports.py`, `integrations/`, `ingestion/` |
| **OpenAPI** | Стандартное описание API в YAML/JSON · *спецификация API* | `openapi.yaml`, `/docs` |
| **Contract-first** | Сначала описать API в контракте, потом писать код | ADR 0001 |
| **ADR** | Architecture Decision Record — короткий документ «что решили и почему» | `docs/decisions/` |
| **CLI** | Программа для терминала · *командная строка* | `langapp` команды импорта |

## База данных

| Term | Объяснение | Где |
|---|---|---|
| **PostgreSQL** | Реляционная база данных | Docker, порт 5433 |
| **Table / Row / Column** | Таблица / строка / столбец | 17 таблиц |
| **Primary key (PK)** | Уникальный идентификатор строки · *первичный ключ* | `id` |
| **Foreign key (FK)** | Ссылка на строку другой таблицы · *внешний ключ* | `lesson_sentences.lesson_id` |
| **Index** | Структура для быстрого поиска · *индекс* | `next_review_at` и др. |
| **Constraint** | Правило, которое база не даст нарушить · *ограничение* | `CHECK mastery_level BETWEEN 0 AND 5` |
| **ORM** | Работа с таблицами как с объектами Python · *объектно-реляционное отображение* | SQLAlchemy |
| **Migration** | Версионированное изменение схемы базы · *миграция* | Alembic, 6 штук |
| **Transaction** | Группа операций «всё или ничего» · *транзакция* | один запрос = одна транзакция |
| **Upsert** | «Вставь, а если уже есть — обнови» | прогресс, импорт |
| **Idempotent** | Повтор операции даёт тот же результат · *идемпотентный* | импорт Tatoeba, `POST /mnemonics` с ключом |
| **Idempotency-Key** | Заголовок с уникальным ключом одной операции; сервер по нему узнаёт повтор · *ключ идемпотентности* | `POST /mnemonics`, таблица `idempotency_keys` |
| **Race condition** | Два запроса одновременно меняют одни данные и мешают друг другу · *состояние гонки* | решено блокировкой строки ключа |
| **Spaced repetition** | Повторение через растущие интервалы · *интервальное повторение* | `mastery` 0–5, 2^mastery дней |

## Безопасность и авторизация

| Term | Объяснение | Где |
|---|---|---|
| **Authentication** | Проверка «кто ты» · *аутентификация* | Supabase Auth |
| **Authorization** | Проверка «что тебе можно» · *авторизация* | `AdminUser`, фильтр по `user_id` |
| **JWT** | Подписанный токен с данными пользователя | заголовок `Authorization: Bearer` |
| **Secret / API key** | Пароль для сервиса; хранится только на сервере | `.env` |
| **Signed URL** | Временная ссылка на приватный файл · *подписанная ссылка* | картинки, 1 час |
| **CORS** | Правило браузера: какие сайты могут вызывать ваш API | не настроен (Vite proxy) |
| **Rate limiting** | Ограничение числа запросов · *ограничение частоты* | 30 AI-вызовов/день, 5 картинок/24 ч |
| **Prompt injection** | Текст пользователя пытается изменить инструкции модели | риск у Carla |

## AI

| Term | Объяснение | Где |
|---|---|---|
| **LLM** | Большая языковая модель, продолжает текст · *большая языковая модель* | OpenRouter |
| **Prompt / System prompt** | Инструкция для модели; system prompt задаёт роль · *промпт* | в каждом агенте |
| **Token** | Кусочек текста, единица счёта для модели · *токен* | `ai_usage.tokens` |
| **Temperature** | «Креативность» модели: ниже — предсказуемее | 0.2 |
| **Structured output** | Модель отвечает в заданном формате (JSON) | все агенты |
| **Agent** | Программа с ролью, использующая LLM; в полном смысле — сама выбирает действия и инструменты в цикле | 5 агентов |
| **Orchestrator** | Код, который управляет агентами: кто, когда, по каким правилам | `AgentOrchestrator` |
| **Tool calling** | Модель просит вызвать функцию, код выполняет её и возвращает результат | не реализовано |
| **Workflow vs agent** | Workflow — путь задан кодом; агент — путь выбирает модель | TurtleTalk = workflow |
| **Hallucination** | Модель уверенно выдумывает · *галлюцинация* | «Never invent facts» в промптах |
| **Fallback** | Запасной вариант при сбое · *резервный вариант* | запасные модели, эмодзи |
| **Cache** | Сохранённый ответ для повторного запроса · *кэш* | `ReplyCache`, 500 ответов |
| **Semaphore** | Счётчик свободных «мест» для одновременной работы · *семафор* | 4 слота |
| **MCP** | Model Context Protocol — стандарт, как AI-ассистент получает инструменты и данные | MCP-сервер, 5 инструментов |
| **Evals** | Набор тестовых заданий для оценки качества модели | в планах |
| **OpenRouter** | Сервис-посредник: один API — много моделей | текст и картинки |

## Надёжность и инфраструктура

| Term | Объяснение | Где |
|---|---|---|
| **Timeout** | Сколько ждать один ответ · *тайм-аут* | 5/10/15 с |
| **Retry** | Повторная попытка после сбоя | OpenRouter, Tatoeba |
| **Exponential backoff** | Паузы между повторами растут: 1, 2, 4… с | Tatoeba |
| **Graceful degradation** | Часть функций отключается, но приложение работает · *плавная деградация* | без AI-ключей |
| **Stateless** | Сервер не хранит состояние между запросами | почти весь бэкенд |
| **Docker** | Запуск программ в изолированных контейнерах | PostgreSQL |
| **CI/CD** | Автоматические проверки (CI) и выкладка (CD) | GitHub Actions — только CI |
| **Linter** | Инструмент, который находит ошибки стиля и кода | ruff, ESLint |
| **Observability** | Возможность понять, что происходит внутри системы: логи, метрики, трейсы · *наблюдаемость* | логи + `ai_usage`; Grafana в планах |
| **Proxy** | Посредник, пересылающий запросы | Vite proxy `/api` → :8000 |
